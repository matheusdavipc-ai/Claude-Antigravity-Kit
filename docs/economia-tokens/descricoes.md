# Inventário de Descrições de Skills, Agentes e Workflows (Passo 5)

Todas as 69 descrições do kit (`30` skills de domínio, `11` skills de workflow, `17` agentes e `11` workflows em `global_workflows`) foram revisadas seguindo os critérios:
- **1 a 2 frases curtas**, começando sempre por **`"Use quando..."`** (ou `"Use somente quando..."` para documentação sob demanda).
- **Gatilhos reais em português** do jeito que o usuário digita no dia a dia (`site`, `landing page`, `página de vendas`, `painel`, `carrossel`, `anúncio`, `orçamento`, `proposta`, `site lento`, `raspar site`, `subir pro ar`, etc.) + termos técnicos consagrados (`React`, `Next.js`, `Tailwind`, `Playwright`, `OWASP`, `Core Web Vitals`).
- **Zero competição de gatilhos** entre skills ou entre agentes do mesmo domínio.
- **Agente de exploração somente-leitura em Haiku:** `explorer-agent` está configurado com `model: haiku` e `tools: Read, Grep, Glob` no próprio frontmatter (sem forçar `CLAUDE_CODE_SUBAGENT_MODEL=haiku` globalmente).
- **Deduplicação de comandos no prompt fixo:** os 11 arquivos de `bundle/global_workflows/*.md` receberam `disable-model-invocation: true`, mantendo os atalhos `/plan`, `/create`, `/debug`, etc. funcionando para o usuário, mas eliminando a duplicação com `workflow-*` na descrição da ferramenta `Skill`.

## 2. Cinco Exemplos Antes vs. Depois

### `avoid-ai-writing` (411 chars → 164 chars)
- **Antes:** `Audit and rewrite content to remove AI writing patterns ("AI-isms"). Use this skill when asked to "remove AI-isms," "clean up AI writing," "edit writing for AI patterns," "audit writing for AI tells," or "make this sound less like AI." Supports a detect-only mode, an edit-in-place mode for files, an optional voice profile (casual / professional / technical / warm / blunt), and an iterate-to-convergence pass.`
- **Depois:** `Use quando for escrever ou revisar textos para humanos (copy de site, landing page, carrossel, anúncio, orçamento, proposta, e-mail ou post) removendo vícios de IA.`
- **Gatilhos:** `copy, texto de site, landing page, carrossel, anúncio, orçamento, proposta, remover cara de ia, humanizar texto`

### `impeccable` (895 chars → 148 chars)
- **Antes:** `Use when the user wants to design, redesign, shape, critique, audit, polish, clarify, distill, harden, optimize, adapt, animate, colorize, extract, or otherwise improve a frontend interface. Covers websites, landing pages, dashboards, product UI, app shells, components, forms, settings, onboarding, and empty states. Handles UX review, visual hierarchy, information architecture, cognitive load, accessibility, performance, responsive behavior, theming, anti-patterns, typography, fonts, spacing, layout, alignment, color, motion, micro-interactions, UX copy, error states, edge cases, i18n, and reusable design systems or tokens. Also use for bland designs that need to become bolder or more delightful, loud designs that should become quieter, live browser iteration on UI elements, or ambitious visual effects that should feel technically extraordinary. Not for backend-only or non-UI tasks.`
- **Depois:** `Use quando o usuário pedir para criar, redesenhar ou melhorar o visual de um site, landing page, página de vendas, painel, carrossel ou seção de UI.`
- **Gatilhos:** `site, landing page, página de vendas, painel, dashboard, carrossel, seção, hero, redesign, melhorar visual, ui/ux, formulário`

### `performance-profiling` (391 chars → 144 chars)
- **Antes:** `Use when a site or app is slow and you need to measure and fix it. Covers Core Web Vitals (LCP, INP, CLS) targets and when to measure, the profile-then-optimize workflow, bundle analysis, runtime CPU/memory profiling, common bottlenecks by symptom, and quick-win priorities. Trigger on: slow load, performance, profiling, bundle size, Lighthouse, memory leak, jank, Web Vitals, optimization.`
- **Depois:** `Use quando um site ou sistema estiver lento ou pesado e precisar medir e corrigir nota do Lighthouse, Core Web Vitals (LCP, INP, CLS) ou bundle.`
- **Gatilhos:** `site lento, página pesada, travando, lighthouse, pagespeed, core web vitals, lcp, cls, inp, bundle grande`

### `scrapling` (706 chars → 148 chars)
- **Antes:** `Web scraping and crawling with the Scrapling Python library (CLI, Python code or MCP server). Use when the user wants to scrape, crawl, collect or extract data from websites (raspar site, extrair dados, coletar informações, crawler, spider, scraper); when WebFetch fails, comes back empty or blocked, or the page needs JavaScript; when the site has anti-bot or Cloudflare protection; to turn pages or whole sites into clean Markdown for LLM/RAG; to parse HTML with CSS/XPath selectors or migrate from BeautifulSoup/Scrapy; or to write Python scrapers and spiders with sessions, proxies, pagination, captured API responses and pause/resume. Not for filling forms by hand in the user's own logged-in browser.`
- **Depois:** `Use quando o usuário pedir para raspar site, extrair dados, coletar contatos/preços/imóveis da web ou criar scraper/crawler em Python com Scrapling.`
- **Gatilhos:** `raspar site, extrair dados, coletar dados de site, scraper, crawler, scrapling, passar por cloudflare`

### `seo-fundamentals` (400 chars → 148 chars)
- **Antes:** `Use when optimizing a page or site for search ranking and visibility. Covers E-E-A-T, Core Web Vitals, technical SEO (site structure, crawlability), on-page elements (titles, meta descriptions, headings), schema/structured-data markup, AI-content guidelines, and prioritized ranking factors. Trigger on: SEO, ranking, search visibility, meta tags, structured data, sitemap, keywords, Google indexing.`
- **Depois:** `Use quando for otimizar um site ou página para aparecer no Google e em IAs (SEO local/técnico, title, meta description, JSON-LD, sitemap e E-E-A-T).`
- **Gatilhos:** `seo, aparecer no google, posicionar site, meta tags, json-ld, schema.org, sitemap, indexação, e-e-a-t`
