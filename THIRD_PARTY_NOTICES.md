# Origem dos componentes

Claude Code e Antigravity são produtos independentes. Os instaladores baixam seus componentes oficiais; este repositório não redistribui executáveis nem contas.

O bundle de skills, agentes e workflows deriva do Kit-Claude-Antigravity fornecido pelo proprietário. Mantém avisos, autoria e licenças existentes em cada componente. Não há relicenciamento global dos conteúdos de terceiros.

Origens registradas no kit:

- Impeccable: <https://github.com/pbakaus/impeccable>
- Design Motion Principles: <https://github.com/kylezantos/design-motion-principles>
- Scrapling (skill oficial da biblioteca, de Karim Shoair/D4Vinci): <https://github.com/D4Vinci/Scrapling>, licença BSD 3-Clause em `bundle/skills/scrapling/LICENSE.txt`. Adaptações do kit: nome `scrapling`, descrição ampliada para descoberta e nota de ambiente virtual no Windows.
- Avoid AI Writing: consulte `bundle/skills/avoid-ai-writing/LICENSE`, seus arquivos de autoria e README.
- As demais origens e adaptações devem ser verificadas nos respectivos arquivos antes de redistribuição sob uma nova licença. O kit original não trouxe uma licença única para todo o bundle, portanto nenhuma licença abrangente foi inventada aqui.

Os arquivos de origem do kit não contêm dados de projeto necessários à instalação. Notas, dados, contextos de clientes, MCP autenticado e configurações privadas foram excluídos do bundle.
